# セッション記録

- 保存: YYYY-MM-DD HH:MM（絶対時刻）
- セッション: <session_id>
- 作業ディレクトリ: `<pwd>`
- ブランチ / HEAD: `<branch>` / `<short sha>`

## 目標

> ユーザーの依頼を原文で引用する（複数あれば新しいものを下に）

## ユーザーのルール・制約

- R-1: 「原文の引用」（いつ言われたか。例: 2026-10-20 の /save 前の依頼）

## 確定した事実

- F-1: 事実（出典: `path:line` / 実行したコマンドと結果の要点 / コミット）

## 決定と理由

- D-1: 決定。理由。決めた主体（ユーザー / Claude の判断）。却下した案があれば併記

## 試して失敗したこと

- X-1: 試したこと → 結果（エラーは原文） → 駄目だった理由

## 再読先

- `path`（何を確かめるために読むか）
- `git log <range>` / 再実行するコマンド

## 変更の状態

- 未コミット: `path`, ... / コミット済み（未 push）: `sha` / push 済み / PR: URL

## 未完了

- [ ] T-1: 内容（出所: ユーザー依頼 / Claude の判断）（完了条件: 何で確かめるか）

## 次の一手

1つだけ。具体的な行動（どのファイルに何をするか、どのコマンドを打つか）。

目標の再掲: 1行で。
